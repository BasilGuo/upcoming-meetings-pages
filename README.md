## About

This service automatically compiles upcoming meetings from folloing internet governance and routing security organizations, namely IETF, APNIC / APRICOT, RIPE, ICANN, NANOG and MANRS, on a daily basis. The meetings are sorted in ascending order by event date to help you learn about and plan your attendance in advance.

Below are the source websites for the meetings. You may also visit the official websites of each organization directly for the latest updates:

- 🌐 [IETF Upcoming Meetings](https://www.ietf.org/meeting/upcoming/)
- 🌐 [APNIC Conferences](https://www.apnic.net/events/conferences/)
- 🌐 [RIPE Upcoming Meetings](https://www.ripe.net/meetings/ripe-meetings/upcoming-ripe-meetings/)
- 🌐 [ICANN Meetings Calendar](https://meetings.icann.org/en/calendar)
- 🌐 [NANOG Future Conferences](https://nanog.org/events/future/?type=conference)
- 🌐 [MANRS Events](https://manrs.org/resources/events/)
